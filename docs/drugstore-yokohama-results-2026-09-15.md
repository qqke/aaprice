# 横滨市药妆店采集入库结果（2026-09-15）

本轮采集并核验 495 家横滨市零售药妆店，已写入数据库并逐条回读验证。新增 5 家，刷新已有 490 家；其中 21 家已有记录的持久化字段发生变化。

本次清单不计入纯调剂药局。数据库原有 25 条纯调剂记录保持原状，因此横滨原始 stores 记录数为 520；不能将这个原始数作为零售药妆店数量。

另采集到 4 家アインズ＆トルペ，已保存地址、电话、营业时间及官方详情，但没有可验证店铺坐标，尚未入库。覆盖范围为本轮核查的官方连锁目录，不宣称包括横滨所有独立药妆店。

## 校验和修正

- 官方目录全量/分页计数核对；仅接受横滨营业中的零售店。
- Sundrug 按官方 listing ID 映射已有记录；Welcia 系按官方店码映射，避免编号规则变化产生重复。
- Welcia/HAC/Kokumin/Welpark 请求明确指定 datum=wgs84，避免默认日本测地系造成数百米偏移。
- 修正 CREATE SD 重复县名前缀、龍生堂横滨门店错误的“東京都”字段。
- 保留官网本次未返回的已有营业时间，避免清空有效数据。
- 数据库逐条回读：495 条，缺失 0，字段不一致 0。
- 17 项既有解析、去重、SQL安全测试通过。
