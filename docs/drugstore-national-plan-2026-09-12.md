# 日本药妆连锁大全：执行计划

范围：日本全国药妆连锁，优先游客购物；不扩展独立调剂药局目录。药妆店内附设调剂柜台不重复算作一家门店。

1. 盘点官方入口与已入库门店，以每个连锁的可枚举官方目录为分母。分别记录发现、成功、排除、失败和已入库数量，不能以一次采样冒充全国完整覆盖。
2. 补齐已有来源的门店；新增杉药局、Cosmos、Create SD、Tomod’s、Satsudora、SEIMS、大国药妆等来源。优先使用官网实际使用的公开目录数据，随后解析详情页；逐来源限速、缓存、断点恢复，拒绝访问的来源保留原因。
3. 保留名称、连锁、地址、坐标、营业时间、官方链接、采集时间；免税等游客信息只记录明确证据，未知不推定。排除未开业、停业、纯调剂及不属范围的业态，缺少坐标的记录待补充而不捏造。
4. 按来源门店 ID 幂等更新，并检查名称、地址的跨来源重复。保留现有记录，不因抓取失败而删除门店。
5. 商品以既有 JAN 为主扩充跨店价格，核实规格、含税口径、库存及是否会员价。网店价格继续仅归属网店；无公开报价的门店可以进入大全，但不能展示推测价格。
6. 分批入库并复查，输出连锁覆盖表和未完成清单。后续刷新机制依据各来源能力制定；本轮不擅自设置定时任务。

本轮已完成首批可公开枚举来源的全国门店扩展：合并 13,232 条官方目录记录后，数据库门店总数为 17,480 家、连锁字段 65 个；同一门店按来源稳定 ID 幂等更新。Cosmos、SEIMS 和部分区域连锁仍需继续补齐或解决官方接口限制。此计划是持续覆盖目标，不承诺一次抓取覆盖所有连锁、所有商品及每家实体店的实时价格。
