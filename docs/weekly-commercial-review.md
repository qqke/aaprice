# AAPRICE 每周商业复盘

每周一使用管理后台“业务”页的 7 天窗口复盘上一周期。记录数字、异常原因和一项负责人明确的改进动作；不为短期波动同时修改多个业务参数。

## 核心门槛

| 指标 | 门槛 | 未达标时优先动作 |
| --- | ---: | --- |
| 热门商品近期报价覆盖率 | ≥ 70% | 从“优先补价商品”领取补价任务 |
| 空查价率 | ≤ 30% | 补齐高访问商品的门店报价 |
| 查价后行动率 | ≥ 15% | 检查地图、比价与商业出口是否清晰可用 |
| 任务领取 → 提交率 | 逐周提升 | 检查任务门店、有效期和录入步骤 |
| 7 日内回访率 | ≥ 15% | 优先改善收藏回访和价格变化价值 |

## 复盘记录

1. 记录 7 天指标，并与 30 天基线比较。
2. 标记偏离门槛最大的一个指标。
3. 写下原因假设、负责人和下周验证动作。
4. 下周先验证结果，再决定是否调整积分或任务参数。
