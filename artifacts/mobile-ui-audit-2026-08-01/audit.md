# AAPRICE 移动端 UI 审视

视口：390 × 844。范围：访客主页、商品目录、扫码、商品详情、登录入口。

## 流程健康度

1. 主页入口：良好，但首屏偏长。
2. 商品浏览：需优化，单卡信息密度低且高度过大。
3. 扫码检索：良好，主要和备用路径都在一屏内。
4. 商品详情：一般，缺少明确返回入口且空字段重复。
5. 登录入口：一般，表单清楚但触控目标偏小。

## 主要发现

- 品牌、颜色、圆角、字体与图片语言一致，整体视觉已经稳定。
- 主页在看到完整商品操作前需要较长滚动；移动端应进一步压缩品牌宣言区。
- 商品卡接近一整屏高，“规格未登记”“商品说明未登记”等低价值字段占据主要空间。
- 页头扫码、账户、主题按钮约 32–36px；登录页主按钮约 32px，注册与忘记密码约 28px，低于推荐的 44px 触控高度。
- 商品详情没有明确的返回搜索结果入口；从详情继续比较的路径不够直接。
- 登录表单没有显示密码入口，注册与找回密码的点击区域偏小。
- 扫码弹窗在 390px 下完整容纳相机与手动 JAN 输入，结构是当前最成熟的移动端流程。

## 优先建议

1. 所有主要触控控件最小高度提升到 44px。
2. 将移动端商品卡压缩为图片、名称、最低价、门店数和主操作；空字段移入详情。
3. 主页首屏缩短约 25%，让第一张商品卡更早出现。
4. 商品详情增加返回结果按钮，并提供固定底部“查价 / 加入比较”操作区。
5. 登录页增加显示密码，扩大注册与忘记密码触控区域。

## 证据限制

本轮为访客态截图审视；已登录个人中心、后台、软键盘顶起、真实相机权限、屏幕阅读器、200% 缩放和低性能设备动画尚未验证。
