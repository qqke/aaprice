## 核查方法

- 通过项目既有服务器数据库连接读取实际数据库，未使用前端展示上限估算覆盖率。
- 官方门店 ID 优先，其次用品牌、分店名、地址规范化比对；重复品牌前缀、集团后缀、全半角差异不会产生新的门店 ID。
- `--missing-only` 跳过已有门店，疑似搬迁、改名和同源同地址记录进入人工复核，不覆盖既有 ID。仅对 619 条能够与旧解析错误精确对应的ツルハ地址做条件更新，补全遗漏的区/町信息。
- 接受官网明确门店坐标，或官网指定地图实体；公共地图补采需要官方电话或官网域名/官方指定实体 ID、分店名称、市区町村及门牌一致。拒绝地图视口中心、商场实体、身份或门牌不一致的候选。
- 本轮新增门店均经数据库回读，核对 ID、名称、品牌、地址、都道府县、坐标和营业时间。地址修正也已逐条回读核验。

## 官方目录覆盖

主要目录包括：ウエルシア集团、マツキヨ/ココカラ、ツルハ集团、スギ、サンドラッグ、SEIMS、コスモス、アオキ、クリエイト、カワチ、キリン堂、薬王堂、Vドラッグ、セキ、ユタカ、サツドラ、トモズ、ダイコク、ゲンキー等，并补查地方连锁。

コスモス通过[官网完整列表](https://www.cosmospc.co.jp/shop/shop_list.json)穷举 1,727 条，筛选 1,713 条当前零售门店，原有 1,701 条，缺少的 12 条已读取官方详情并补入；已有门店只验证存在，没有宣称全量刷新其营业信息。

区域官网穷举 1,217 条记录：1,044 条可靠零售门店、66 条待核实、107 条调剂专门/关闭等排除记录。可靠零售数量：Mori 432、Zagzag 219、mac 73、Yamazawa 44、Drug39 29、Arka 49、Ainz 92、Sunroad 30、Fit Care 76。数量是本次取得可靠证据的门店数，不等同于每个连锁的全部当前零售店数。

ゲンキー 543 条官网条目中，官网坐标或官网指定地图核验 457 条，公共地图严格核验再取得 60 条；24 条仍待核实，2 条缺少营业身份或状态异常排除。官网证书缺失中间证书时补充了经过可信根验证的官方中间证书，没有关闭 TLS 验证。

Sugiyama 122 条中取得 102 条可靠零售；Ohga/Evergreen 61 条中取得 58 条；YACS/Mine 166 条中取得 140 条。纯调剂、关闭/未来开业以及坐标未核实记录分开保留。

[JACDS 企业目录](https://jacds.gr.jp/member-hp/)用于发现遗漏连锁。页面展示 102 个顶层企业与 28 个子公司项，[协会概要](https://jacds.gr.jp/outline-gaiyo/)标注 2026 年 6 月正会员 101 社；这是不同口径的企业名录，不能当成 130 家药妆品牌或全日本门店名单。集团公司、超市、调剂药局及品牌映射未决项均保留复核状态。

## 剩余限制

- 官网地址与地图门牌不一致、地图只有中心点或无法匹配业务实体的门店不强行入库。区域剩余 66 条、ゲンキー剩余 24 条含此类情况；其他来源的待核实记录见本地完整总账。
- ウエルシア两条疑似搬迁/品牌变化记录已有同分店或同地址候选，保留人工复核，避免重复新增。
- コメヤ官网 22 条按企业业态分组为 16 家零售候选，13 家取得可靠位置并入库，3 家仍因实体或门牌不能核实而待处理。Hashi 16 家全部补录，Asahi 34 家取得可靠坐标，另外 3 条为身份/地址不一致或 Express 业态未定。
- 追加地方连锁取得 86 家可靠门店（含此前 66 家），剩余 8 条。下川官网当前目录只有 11 条药妆门店，企业概况称 12 店，两者差异保留；ヨネキ目录 3 条中核实 1 条。
- セキ原郷店已于 2026-02-19 开业，官网目录仍有过期开业预告且坐标为空，公共地图缺乏足够身份信息，明确列为已开业待位置核实。コーエイ官网实际抓取失败，不能确认其完整目录覆盖。龍生堂 23 条零售候选 ID 已存在，另有化妆品专门店待业态复核，一条详情访问失败但数据库已有记录。
- 数据库原有 995 组规范化重复身份（主要是历史导入）；本轮没有删除这些旧记录，因此数据库行数不能直接作为当前营业零售门店的唯一数量。
- 非会员独立店、超市内药品柜台和未确定业态/企业品牌映射不能由本次官网目录覆盖证明齐全。

## 复现和证据

原始只读快照：`artifacts/drugstores-audit-2026-10-03/database-before.json`。最终对照和待处理分类：`artifacts/drugstores-audit-final-2026-10-03/`；企业映射：`artifacts/drugstores-membership-2026-10-03/`；区域完整总账：`artifacts/drugstores-regional-audit-2026-10-03/`。抓取证据、坐标来源和采集时间都保留在本地 artifacts，凭据和原始缓存不提交。

最终 `summary.json` 保存新增品牌计数和数据库前后差异，`database-verification.json` 回读验证全部 1,192 个新增 ID（missing=0、mismatched=0）。`pending-ledger.json` 汇总 135 条待核实记录，其中 27 个 ID 已存在；其余记录也含业态未定、来源访问失败等情况，不能直接当成 108 家确定遗漏门店。

```powershell
# 只读覆盖核查；可传多个经过核验的 stores.json
node --env-file=.env scripts/audit-drugstore-coverage.mjs PATH/stores.json --out=artifacts/coverage-review
# 先生成待导入清单并审查 import-report.json
node --env-file=.env scripts/import-drugstore-batch.mjs PATH/stores.json --missing-only --out=artifacts/import-review
# 对冻结后的清单执行；再回读验证
node --env-file=.env scripts/import-drugstore-batch.mjs artifacts/import-review/stores.json --missing-only --apply --out=artifacts/import-review
node --env-file=.env scripts/verify-drugstore-batch.mjs --out=artifacts/import-review
```

主要抓取器支持 `--resume` 与 `--offline`，官方分页计数和唯一 ID 必须一致才标记枚举完整。公共地图补采只复核官方目录中的候选，不用地图搜索结果扩充未经证明的店铺身份。

验证：`npm test` 全部 110 项通过，`npm run build` 通过，`git diff --check` 通过。完整抓取清单的最终只读对照为 missing=0、身份歧义=2；全部新增数据最终统一回读为 checked=1192、missing=0、mismatched=0。部署结果另以对应提交的 GitHub Actions 运行状态为准。
