# 简洁与触屏操作打磨 · 2026-10-25

- 保留现有视觉和流程，未引入新依赖、页面、导航层级或数据接口。
- 扫码工具栏改为自适应网格；320px 宽时四个操作保持同一行且不越界，更窄时允许换行。缩短暂停、补光的可见文案，保留完整可访问名称和补光状态。
- 手动输入增加 48px 清空按钮，清空后保留输入焦点并移除旧错误；输入与主按钮至少 48px，提示减去重复术语。查询仍紧跟输入，未将它固定到容易被键盘覆盖的屏幕底部。
- 未收录结果将信息与操作分开，重新扫描等操作位于手机屏幕下半部；短屏通过自然滚动保留完整内容。扫码页头保持可见，长补录表单滚动后仍可关闭，滚动不会继续穿透到背景页面。
- 商品页底部使用贴边操作栏，保留安全区内边距；主动作占剩余宽度，收藏收为 48px 图标并使用 `aria-label`、`aria-pressed` 表达用途与状态。长按钮文字允许换行，不挤压收藏。
- 触屏设备的组件按钮、原生选择框和折叠标题至少 44px；输入、选择框及文本域使用至少 16px 字号，减少输入时界面缩放的风险。折叠标题增加上下留白，保留原生语义和键盘操作。

验证：`npm test` 221 项，219 通过、2 跳过；构建通过。隔离浏览器启用触屏输入，检查 320/375/390px 下按钮尺寸、位置、换行及溢出，验证清空、收藏切换、短屏输入和长表单滚动关闭，并通过原有扫码与业务回归。截图位于忽略目录 `artifacts/commercial-audit/`。
